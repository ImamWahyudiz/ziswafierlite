Masalah

Mengapa Rekonsiliasi ZISWAF Sulit?

Lembaga amil menghadapi tantangan unik saat memproses ribuan transaksi masuk setiap bulan

Noise Format Bank

Label mutasi terpotong BI-FAST/RTGS/QRIS dan bercampur ID dompet digital. Data tidak terstruktur dari berbagai bank berbeda.

Bahasa Non-Baku Donatur

Sinonim bebas: "bantuan sumur" (Wakaf Air), "beras santri" (Gizi Santri), typo "iph" untuk zakat profesi.

Kepatuhan Syariah

Dana Zakat & Wakaf dilarang keras dicampur atau ditebak sembarangan. Butuh sistem yang akuntabel dan transparan.

Solusi

Pipeline Klasifikasi 5-Lapis

Setiap baris mutasi diproses melalui pipa hybrid: deterministik cepat + AI semantik cerdas

0

Text Sanitizer & Alias Filter

Pembersihan noise format bank (BIFAST, RTGS, QRIS, e-wallet) & ekstraksi nama pengirim.

Deterministik
1

Outflow / Expense Filter

Deteksi transaksi minus atau label "TRF KE" → COA 60100008 (Beban Lain-Lain).

Instant
2

Campaign Tail Code (Kode Ekor)

Pencocokan 3-digit unik nominal donasi per program kampanye.

95% Akurat
3

Donatur Tetap Matching

Pencocokan nama pengirim ke database donatur tetap amil.

90% Akurat
4

Keyword & Dictionary

Pencocokan kata kunci syariah ("fidyah", "wakaf", "gizi santri", "zakat maal").

90% Akurat
5

AI Semantic / Unauthorized Fallback

Pencocokan konteks AI semantik (Ollama/Gemini/OpenAI) atau karantina ke 40201000 Unauthorized.

AI / Karantina
Fitur

Yang Membuat ZISWAFier Berbeda

Didesain khusus untuk efisiensi amil dan kepatuhan akuntansi syariah

Hybrid 5-Layer Pipeline

Layer 0–4 deterministik (<10 detik/2000+ baris) + Layer 5 AI semantik untuk kasus kompleks.

Pencocokan Donatur Tetap

Subset-name matching dua arah tanpa library berat — akurat untuk variasi nama transfer perbankan.

Kode Ekor Nominal

3 digit unik per program — klasifikasi otomatis 95% tanpa perlu memanggil API AI.

Akun Karantina Mutlak

Dana tanpa keterangan dialokasikan ke Unauthorized (40201000) untuk menjaga kehati-hatian syariah.

WhatsApp Confirmation

Generate pesan konfirmasi donasi instan via tautan WhatsApp Web ke nomor donatur terdaftar.

Ekspor Jurnal SIAK

Format jurnal rapi siap impor ke software akuntansi dalam format Excel (.xlsx) dan CSV.

Model Tata Kelola Dua Lapis

Pemisahan otoritas yang tegas antara Admin Keuangan & Kepala Divisi

Admin Keuangan
  • Upload mutasi bank (.xlsx/.csv)
  • Koreksi alokasi COA & aksi massal
  • Kirim konfirmasi WA ke donatur
  • Ekspor jurnal bersih kapan saja
Kepala Divisi (Kadiv)
  • Satu-satunya otoritas reklasifikasi Unauthorized
  • Setujui perubahan program via respons WA
  • Konfigurasi global AI & WhatsApp Gateway
  • Tutup Buku (Closing Date Lock)
